# Free AI Implementation Plan

> For agentic workers: execute inline with superpowers:executing-plans. The user delegated provider selection and implementation.

**Goal:** Free-tier Cloudflare, local Ollama option and reliable adventure flow.
**Architecture:** Native fetch server adapters, bounded validated JSON contracts; React hook owns cancellation, errors and persistence.
**Tech Stack:** Next.js/React, Tailwind, TypeScript, Biome, Node tests, Playwright.
**Spec:** ../specs/2026-11-04-free-ai-design.md

## Global Constraints
- Spanish fantasy chat; secrets server-only; no automatic paid fallbacks.
- Preserve original .env.local and unrelated user changes.
- Never claim live AI success without an actual successful request.

## Review Focus
- Missing credentials or quota exhaustion: useful errors without leaked secrets.
- Corrupt/full storage: gameplay remains usable.
- Rapid submits, reset race and StrictMode: no duplicate/stale turns.
- Large history/base64 or invalid JSON: bound or reject before upstream calls.
- Image failure: retry separately while preserving narrative.
