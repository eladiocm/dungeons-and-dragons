# SRD solo MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Convertir el chat 0.3.0 en una partida SRD 5.2.1 de nivel 1 con creación, motor autoritativo, aventura completa, mesa móvil y voz.

**Architecture:** Dominio puro `src/game`, orquestación/persistencia en `src/server` y componentes de mesa en `src/app`. Conservar proveedores y PWA existentes cuando sean compatibles. Eventos/versiones/idempotencia protegen efectos mecánicos frente a reintentos; el Master solo propone y narra.

**Tech Stack:** Next.js 16.4.5, React 19.3.1, TypeScript 7, Node 24 comprobado; SQLite con API de runtime verificada; node:test y Playwright. SVG/CSS para iconos/dados; Web Speech/MediaRecorder y transcripción por servidor como alternativa.

**Spec:** `docs/superpowers/specs/2026-11-05-mvp-srd-design.md`, aprobada por el usuario el 5 de noviembre de 2026, incluidas limitaciones de seguimiento aproximado/dictado al soltar.

## Global Constraints

- SRD 5.2.1 en español; personajes de nivel 1; guerrero, pícaro, clérigo y mago.
- Primero una aventura preparada con acciones libres. Después, una modalidad de mundo abierto elegible al crear partida.
- La IA siempre dirige como Master. El jugador decide sus acciones; la IA no las elige por él.
- Creación y revisión de personaje antes de habilitar Iniciar partida.
- Un jugador ahora, tipos con sesión/participantes/actorId desde el inicio.
- Micrófono: pulsar dicta, soltar detiene, revisión y envío explícito. Nunca autoenviar.
- Narración automática tras iniciar, desactivable; escena ilustrada siempre presente; móvil/PWA.
- Trabajar en develop y conservar claves, datos y main. Catálogo reducido explícito, sin opciones ficticiamente implementadas.

## Review Focus

- Dos pestañas/reenvíos tras timeout: efectos y resultados de dados se aplican una sola vez (Tareas 4/5).
- Humano + trasfondo/clase con competencias o conjuros repetidos: ficha válida sin perder elecciones ni duplicar bonificadores (Tareas 1/3).
- Dados opcionales, inspiración y recursos de dote: elección antes del cierre, sin crear rerolls ilimitados (Tareas 2/3/4).
- Permiso de micrófono o `audio.play()` que finaliza tras cancelar: no reactivar captura/audio ni sobrescribir borrador nuevo (Tarea 8).
- Reinicio o cuota IA agotada tras daño guardado: recuperar estado y reintentar prosa sin nueva tirada ni botín (Tareas 5/6).
